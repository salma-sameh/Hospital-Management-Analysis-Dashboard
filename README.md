# 🏥 Hospital Management Analysis Dashboard

### Turning Hospital Data into Actionable Business Insights

## 📌 Project Overview

The **Hospital Management Analysis Dashboard** is a data analysis project developed as the final project of the **NTI Data Analysis Track**.

The project focuses on analyzing hospital management data to understand operational performance, patient demographics, medical services, and financial activities.

By combining SQL Server, Python, and Power BI, the project transforms raw hospital data into meaningful insights that can support data-driven decision-making and improve operational visibility.

## 🎯 Project Objectives

- Analyze hospital operations and patient information.
- Understand patient demographics and distribution.
- Evaluate doctor performance and medical specializations.
- Explore appointment trends and treatment patterns.
- Analyze treatment costs and financial performance.
- Identify trends and patterns that can support better hospital management decisions.
- Build interactive visualizations to communicate analytical findings.

## 🛠️ Tools & Technologies

| Technology | Purpose |
|---|---|
| SQL Server | Database management, relationships, and SQL queries |
| Python | Data cleaning, exploration, and analysis |
| Pandas & NumPy | Data manipulation and transformation |
| Matplotlib & Seaborn | Statistical analysis and visualization |
| Power BI | Interactive dashboards and business reporting |

## 🔄 Project Workflow

The project follows a structured data analysis workflow:

### 1. Database Exploration & SQL Analysis

- Explored the hospital database and its related tables.
- Examined table structures, relationships, and data types.
- Created and analyzed relationships between tables.
- Used SQL queries to retrieve and analyze relevant information.
- Applied JOINs, aggregate functions, GROUP BY, subqueries, and other SQL techniques.

### 2. Data Cleaning

Using Python and Pandas:

- Inspected datasets and identified missing values.
- Checked for duplicate records and inconsistent values.
- Corrected data types.
- Standardized date and time columns.
- Handled missing and inconsistent data.
- Prepared datasets for further analysis.

### 3. Exploratory Data Analysis (EDA)

Explored the datasets to understand their structure, distributions, and patterns.

The analysis focused on:
- Patient demographics and age distribution.
- Gender distribution.
- Doctor and department information.
- Appointment patterns.
- Treatment types and associated costs.
- Hospital financial activities.

### 4. Feature Engineering & Data Transformation

- Created additional analytical features.
- Derived meaningful information from existing columns.
- Prepared data for more effective analysis and visualization.
- Applied appropriate data transformations and normalization techniques where needed.

### 5. Dashboard Development

Developed interactive Power BI visualizations to present key performance indicators (KPIs), trends, and analytical findings in an understandable format.

## 📊 Key Business Questions

The project investigates important business questions, including:

1. How are patients distributed across different demographic groups?
2. Which doctors and medical specializations have the highest activity?
3. What are the trends in hospital appointments?
4. Which treatment types incur the highest average cost for patients?
5. How does hospital revenue and payment activity vary?
6. What patterns can be identified in hospital operations and financial performance?

## 💡 Business Value

The analysis demonstrates how healthcare data can be used to:

- Support operational monitoring.
- Understand patient distribution and service demand.
- Evaluate treatment costs.
- Monitor financial performance.
- Identify trends that may help management make informed decisions.
